ExporterPack

DeeNWCs

Browse your ACC/BIM360 project, batch-open selected Revit files, and export every view with 'NAVIS' in its name to NWC — to a local folder or straight to an ACC folder.

Risk level: Low Read-only against the model (just exports NWC files) — no sync or publish happens. With ACC output it adds files, new versions and folders to the ACC folder you pick; it never deletes anything there.

What it does

Logs into ACC/BIM360 (opens your browser once to sign in), lets you pick a Hub and Project, then check off which cloud Revit files to process. For each file, it opens it and exports every view whose name contains "NAVIS" to an NWC file — useful if your team keeps a dedicated "NAVIS" 3D view per model for Navisworks coordination exports.

How to use it

  1. Sign in to ACC when prompted (first run only — the login is cached for about an hour).
  2. Pick a Hub, then a Project.
  3. Use the cached file list or rescan the project.
  4. Check which files to process.
  5. Run — review the colored results report at the end.

Saving on ACC

  • Under Output choose ACC / BIM360, then CONTINUE.
  • The first time, pick Hub, Project and folder. In any folder use [+ Add a new folder here...] to create one, [Save in this folder] to take it, [.. Back] to go up. ACC does not allow new folders at the project's own root, only inside Project Files and below.
  • Next time, the last folder is offered as it is, or with a new folder inside it.
  • A file that is already in the folder gets a new version. The Folder structure subfolders are created on ACC when missing.
  • Every file is uploaded right after its export. If an upload fails you can try again at the end; the file stays on this PC and the report shows where.
  • Scheduled exports save to the task's output folder and upload from there.
  • You need Create (upload) permission on the ACC folder. The first use asks you to sign in to Autodesk once more, to allow creating files.

Before you run it

  • Requires acc_config.json (ask your administrator if you see a message that it's missing) and valid ACC/BIM360 access to the target hub/project.
  • Each processed file needs at least one view with "NAVIS" in its name, or nothing will export for it.

Exporting with more than one Revit

  • Under Run by choose More than one Revit and how many (2 or 3 is usual; each needs its own memory).
  • Background Revits are started for you, split the models between them and close themselves when done. This Revit shows their progress and the combined results.
  • The background Revits are started with the Navisworks exporter loaded (a plain background Revit has none of your add-ins).
  • Each model is opened detached and never saved or synchronized. Revit's open dialogs are answered automatically, and a model that fails to open (“The host model failed to open”) is tried again, then skipped and reported.
  • The exporter’s own message boxes (for example “No suitable geometry found”) are answered automatically, here and in the background Revits. The view then shows as skipped with the exporter’s sentence in the results.
  • If a background Revit crashes (Autodesk’s “Error Report” box) or dies, it is ended automatically instead of holding the whole batch. The model it died on is reported as failed, and a new Revit takes the models it had not reached (at most twice per Revit).
  • A model whose View contains text matches no view is shown as skipped, with the model’s own 3D view names beside it so the text is easy to correct.
  • A model that is open in your own Revit is exported from its saved or cloud version, not as it is on screen.
  • Works with local and ACC output.
