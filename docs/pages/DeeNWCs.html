ExporterPack

DeeNWCs

Browse your ACC/BIM360 project, batch-open selected Revit files, and export every view with 'NAVIS' in its name to NWC.

Risk level: Low Read-only against the model (just exports NWC files to disk) — no sync or publish happens.

What it does

Logs into ACC/BIM360 (opens your browser once to sign in), lets you pick a Hub and Project, then check off which cloud Revit files to process. For each file, it opens it and exports every view whose name contains "NAVIS" to an NWC file — useful if your team keeps a dedicated "NAVIS" 3D view per model for Navisworks coordination exports.

How to use it

  1. Sign in to ACC when prompted (first run only — the login is cached for about an hour).
  2. Pick a Hub, then a Project.
  3. Use the cached file list or rescan the project.
  4. Check which files to process.
  5. Run — review the colored results report at the end.

Before you run it

  • Requires acc_config.json (ask your administrator if you see a message that it's missing) and valid ACC/BIM360 access to the target hub/project.
  • Each processed file needs at least one view with "NAVIS" in its name, or nothing will export for it.
