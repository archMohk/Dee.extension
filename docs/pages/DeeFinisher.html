ModelingPack

DeeFinisher

Scan rooms and batch-generate Floor / Wall / Ceiling finishes from room boundaries.

Risk level: Low Everything happens inside one Transaction (undoable). Re-runs use Skip/Replace/Update/Ask so you don't pile up duplicate finish elements.

What it does

Scans Rooms (active view or whole project), lets you assign a Floor Finish Type / Wall Finish Type / Ceiling Finish Type per room — or in bulk via the Global Assignment Panel — previews what will be created, then generates the actual Floor/Wall/Ceiling elements from each room's boundary in one Transaction. Wall Finish is generated in "full" mode: each straight, wall-bounded boundary segment is offset inward by half the finish wall's thickness, corners are mitered, and adjacent segments are joined after creation.

Rooms with zero Area (Unplaced/Not Enclosed) can be filtered out of the scan entirely via a checkbox. A Select Highlighted Rows / Deselect Highlighted Rows pair lets you Shift-click or Ctrl-click a range of rows in the grid, then check them all at once.

How to use it

  1. Scan Rooms (active view or whole project).
  2. Assign Floor/Wall/Ceiling Finish Types per room, or select several rows and use the Global Assignment Panel to apply to all of them at once.
  3. Set Wall Finish Options (height mode) and Duplicate Detection mode (Skip/Replace/Update/Ask for re-runs).
  4. Preview, then Generate.

Before you run it

  • Curved boundary segments fall back to an unmitered offset, and separation-line-bounded segments are skipped for Wall Finish (there's no physical wall to line) — review results and re-run with Replace/Update if a corner needs manual cleanup.
