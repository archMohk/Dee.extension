CreatePack

DeeAligner

Align/distribute Viewports and Images on a sheet, auto-arrange Images into a grid, or import local image files straight onto a sheet.

Risk level: Low Nothing touches Revit until you click Apply to Sheet (Views/Images tabs) or Insert into Sheet (Super Image tab) - every action before that only stages a preview first (shown with a yellow outline in the canvas). Applying happens inside a single Transaction in the current document, isn't synced or published, and can still be undone (Ctrl+Z) like any normal edit.

What it does

DeeAligner has three tabs:

  • Views tab — check any number of sheets in a checklist, then Scan Selected Sheets pools every Viewport on all of them into one grid (each row shows which sheet it came from). The align/distribute buttons then batch-align across that whole pooled set — e.g. Align Left moves every checked Viewport, whatever sheet it's on, so its left edge matches the overall minimum. This works because two sheets of the same paper size share the same sheet-space coordinate system, so it's genuinely useful for putting the main view in the same spot on every sheet in a set.
  • Images tab — pick one sheet (or use your current Revit selection) and work on the Images already placed on it: align/distribute them relative to each other, scale them, check for overlaps, or auto-arrange them into a tidy grid inside the sheet's title block bounds.
  • Super Image tab — pick image files straight from your PC (not yet in the model at all), pick a target sheet, and Preview Arrangement computes a grid that fills the sheet's title block bounds, scaling each image to fit its own cell while preserving its native proportions (a batch of mostly-landscape photos naturally gets a wide grid, mostly-portrait a tall one). Move Up/Move Down reorder images before arranging. Insert into Sheet then actually imports and places them.

Views and Images tabs also have a Center in Sheet option with an Offset X/Y so you can drop an item dead-center in the sheet's title block bounds (nudging away from a title strip if needed), and a live preview canvas that draws the sheet outline plus a box per item so you can see what's about to move before you click anything.

Every alignment/offset/scale/auto-arrange button only stages its result - the grid's Center/Width/Height columns and the preview canvas immediately update to show the outcome (staged items get a yellow outline), but nothing actually changes in the model. Staged actions compose: doing Align Left, then Center in Sheet, computes the second one from the first one's staged result. Click Apply to Sheet (top of each tab) to actually commit every staged change to Revit in one go, or Discard Changes to clear the staged preview without touching anything.

How to use it

Views tab:

  1. Check the sheets you want in the list, then click Scan Selected Sheets (or select Viewports in Revit first and click Use Current Selection).
  2. Check which rows in the grid you want an operation to act on (Include column).
  3. Click an align/distribute button, or set an Offset and click Center Checked in Sheet - this stages the result (yellow outline in the preview), it doesn't move anything yet.
  4. Happy with the preview? Click Apply to Sheet to actually move the checked Viewports. Click Discard Changes instead to back out.

Images tab:

  1. Pick a sheet from the dropdown and click Load Sheet (or Use Current Selection).
  2. Check which Images to act on.
  3. Use Align/Distribute, Scale Images, Auto-Arrange, or Center Checked in Sheet - each one stages a preview only.
  4. Click Apply to Sheet to commit, or Discard Changes to back out. Check for Overlaps is unaffected - it only reports, so it isn't part of the stage/apply flow.

Super Image tab:

  1. Pick a sheet from the dropdown and click Use This Sheet.
  2. Click Add Images from PC... and pick one or more image files (bmp/jpg/jpeg/png/tif/tiff).
  3. Reorder with Move Up/Move Down if you care which order they get packed in, then check the ones you want.
  4. Click Preview Arrangement to see the grid-fit layout in the preview canvas - nothing in the model changes yet.
  5. Happy with it? Click Insert into Sheet to actually import and place them. Inserted rows drop off the list once placed.

Options

Align Left/Right/Top/BottomLines up the checked items' edges to the overall minimum/maximum.
Align Center (H) / Middle (V)Centers checked items on the overall selection's own bounding box.
Distribute Horizontally/VerticallySpaces item centers evenly between the first and last (needs 3+ checked items).
Center in Sheet + Offset X/YMoves each checked item to its sheet's title-block-bounds center, then nudges it by the offset (shown in your project's display unit).
Scale Factor / Match Size to Largest/SmallestImages tab only — resizes checked Images by a multiplier, or matches every checked Image to whichever one is largest/smallest by area.
Auto-ArrangeImages tab only — packs checked Images into a grid, sliding around unchecked Images and Viewports so it doesn't overlap them (best-effort, not guaranteed on a crowded sheet).
Preview Arrangement / Insert into SheetSuper Image tab only — Preview Arrangement computes (but doesn't apply) a grid-fit layout for the checked images against the target sheet's title block bounds; Insert into Sheet actually imports each as a new Revit Image and places it at its previewed position/size.
Move Up / Move DownSuper Image tab only — manually reorders the highlighted row, which changes packing order in the next Preview Arrangement (earlier rows get earlier/left-to-right/top-to-bottom grid cells).

Before you run it

  • Align/Center needs at least 2 checked items; Distribute needs at least 3.
  • "Center in Sheet" uses the sheet's title block bounding box as a stand-in for its usable white space — if your title block has a wide info panel along one edge, use the Offset fields to compensate.
  • A rescan, a fresh Use Current Selection, or loading a different sheet replaces the grid's rows entirely, which also silently discards anything staged but not yet applied — click Apply to Sheet first if you want to keep it.
  • A staged change stays staged even if you later uncheck that row's Include box — unchecking only controls what NEW actions operate on, it doesn't cancel something already staged. Use Discard Changes to clear everything.
  • The Super Image tab uses Revit API calls (ImageType.Create, ImageInstance.Create) that no other tool in this extension has ever used before — verified against the official API docs before building, but not yet exercised live. Try it on a backup/non-production sheet first.
  • Super Image's grid-fit layout also uses the sheet's title block bounding box as a stand-in for usable white space, same caveat as Center in Sheet — a busy title block can eat into the area it tries to fill.
