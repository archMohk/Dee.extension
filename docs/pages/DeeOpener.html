BatchPack

DeeOpener

Browse your ACC/BIM360 project, pick multiple Revit files by checkbox, and open them in bulk — either normally or with all worksets closed.

Risk level: Low Purely opens files — nothing is written, synced, or published.

What it does

The simplest of the batch-opening tools: logs into ACC/BIM360, lets you pick a Hub and Project, then check off files and open them all in sequence, either normally or with all worksets closed. Files are left open for you to work with.

How to use it

  1. Sign in to ACC, pick Hub → Project.
  2. Use the cached file list or rescan the project.
  3. Check which files to open.
  4. Pick Regular Open or Open with All Worksets Closed.
  5. Run — review the colored results, including any auto-dismissed dialog notes.

Before you run it

  • Opening many large files at once can be slow/resource-intensive on this machine, even though it isn't destructive.
