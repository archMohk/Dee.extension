CreatePack

DeeSheet

Create sheets in bulk from an Excel paste, or manage every sheet in the project in one editable table.

Risk level: Low Everything happens inside a Transaction (undoable). Deleting a sheet does remove it permanently once you confirm and apply, so double-check the Delete checkboxes before clicking Apply Changes.

What it does

Two tabs:

  • Normal Creation — paste the Sheet Number column from Excel into one box and the Sheet Name column into the other (line 1 in both = one sheet, line 2 = the next, and so on), pick a Title Block, and batch-create them all. Numbers that already exist are skipped. You can export the results to a themed Excel report.
  • Super Sheet — scans every Sheet already in the project into one editable grid. Edit Number/Name directly in a cell, use Move Up/Move Down to reorder rows in the view (handy for slotting a new sheet between two existing ones), Add Row for a brand-new sheet, and a Delete checkbox per row to mark a sheet for removal. Rows are color-coded by status (green = new, amber = modified, red = to delete). One Apply Changes button creates/renames/deletes everything at once. A Title Block dropdown + Apply to All Sheets button can also swap every existing sheet's title block type in one go.

How to use it

Normal Creation:

  1. Pick a Title Block from the dropdown.
  2. Copy the Sheet Number column from Excel into the left box, and the Sheet Name column into the right box.
  3. Click Create Sheets. Optionally export the results afterward.

Super Sheet:

  1. The grid auto-loads on open (or click Refresh Sheets). Edit any cell directly.
  2. Add Row for a new sheet, fill in its Number/Name, then Move Up/Down to place it where you want.
  3. Check Delete on any row you want removed.
  4. Click Apply Changes — review the create/update/delete counts in the confirmation, then confirm.
  5. For a bulk title block swap: pick a type from the dropdown at top and click Apply to All Sheets.

Options

Title Block dropdownUsed for new sheets on both tabs; "(None)" is a valid choice.
Delete checkbox (Super Sheet)Marks a real sheet for deletion, or just drops a not-yet-created row you added by mistake.
Apply to All SheetsSwaps every existing sheet's title block instance to the selected type (keeps position), or places one on any sheet that currently has none.

Before you run it

  • Sheet Number and Sheet Name boxes must have the same number of lines (Normal Creation).
  • Column sorting is intentionally disabled in Super Sheet's grid so Move Up/Down works reliably — the list just starts sorted by Number from the initial scan.
