CreatePack

DeeSheet

Create sheets in bulk from an Excel paste, manage every sheet in one editable table, or bulk-rename/renumber sheets with a token rule engine.

Risk level: Medium Everything happens inside a Transaction (undoable via Ctrl+Z). Deleting a sheet, and applying the Sheet Renamer's renumbering, are both real changes once confirmed — review the grid/preview before clicking Apply.

What it does

Three tabs:

  • Normal Creation — paste the Sheet Number column from Excel into one box and the Sheet Name column into the other (line 1 in both = one sheet, line 2 = the next, and so on), pick a Title Block, and batch-create them all. Numbers that already exist are skipped. You can export the results to a themed Excel report.
  • Super Sheet — scans every Sheet already in the project into one editable grid. Edit Number/Name directly in a cell, use Move Up/Move Down to reorder rows in the view (handy for slotting a new sheet between two existing ones), Add Row for a brand-new sheet, and a Delete checkbox per row to mark a sheet for removal. Rows are color-coded by status (green = new, amber = modified, red = to delete). One Apply Changes button creates/renames/deletes everything at once. A Title Block dropdown + Apply to All Sheets button can also swap every existing sheet's title block type in one go.
  • Sheet Renamer — bulk-builds new Sheet Numbers/Names from a small token rule (e.g. A-{Serial|PAD3}, {Parameter:Discipline|UPPER}-{SheetNumber|LAST3}), a running sequence (numeric or lettered, with per-group reset), Find & Replace, Add Text, and case conversion — all staged into a Preview grid with a Status column before anything touches the model. Duplicate Sheet Numbers are never silently overwritten.

How to use it

Normal Creation:

  1. Pick a Title Block from the dropdown.
  2. Copy the Sheet Number column from Excel into the left box, and the Sheet Name column into the right box.
  3. Click Create Sheets. Optionally export the results afterward.

Super Sheet:

  1. The grid auto-loads on open (or click Refresh Sheets). Edit any cell directly.
  2. Add Row for a new sheet, fill in its Number/Name, then Move Up/Down to place it where you want.
  3. Check Delete on any row you want removed.
  4. Click Apply Changes — review the create/update/delete counts in the confirmation, then confirm.
  5. For a bulk title block swap: pick a type from the dropdown at top and click Apply to All Sheets.

Sheet Renamer:

  1. Check the sheets to rename (Select All / Select Highlighted, or Search + Filter to narrow the list first — the underlying sheet list always covers the whole project regardless of the filter, so duplicate detection still catches collisions with sheets you've filtered out of view).
  2. Build a rule: type a template into New Sheet Number rule / New Sheet Name rule, using the Insert Token / Insert Parameter Token buttons if you don't want to type the { } syntax by hand.
  3. Set Start/Step, Order rows by, and (optionally) Reset sequence when this changes for a per-group running number.
  4. Click Generate Preview. Optionally layer on Find & Replace, Add Text, or a case-convert button — each one edits the same staged New Number/New Name values, so they combine with the rule and with each other.
  5. Check the Ready/Duplicate/Unchanged/Empty counts and the example row shown in the strip above the table — a quick sanity check before scrolling the full grid (e.g. if everything comes back Duplicate, it usually means the rule doesn't actually use {Serial}/{Alpha}, so every selected row is computing the same value).
  6. Review the Status column (Ready / Unchanged / Empty / Duplicate) — New Number/New Name cells are also directly editable for a one-off tweak.
  7. Click Apply Renumbering and confirm. Duplicate/Empty rows are skipped automatically, never overwritten.
  8. Save a rule as a Preset to reuse it next time (Presets group, bottom left).

Options

Title Block dropdownUsed for new sheets on Normal Creation/Super Sheet; "(None)" is a valid choice.
Delete checkbox (Super Sheet)Marks a real sheet for deletion, or just drops a not-yet-created row you added by mistake.
Apply to All SheetsSwaps every existing sheet's title block instance to the selected type (keeps position), or places one on any sheet that currently has none.
Sheet Renamer tokens{SheetNumber}, {SheetName}, {Parameter:Name} (any instance parameter by name), {Serial}/{Alpha} (the running sequence, as a number or as letters A, B, ... Z, AA, AB, ...), {Date}/{Date:FMT}. Text outside { } is copied as-is, which is how prefixes/suffixes work — no separate field needed.
Sheet Renamer modifiersChain with | after a token: UPPER, LOWER, TITLE, TRIM, PADn, FIRSTn/LASTn, MID:start:len, BEFORE:x/AFTER:x/BETWEEN:x:y, SPLIT:delim:n, NUM/ALPHA (keep only digits/letters), REPLACE:old:new, DEFAULT:fallback (used when the value so far is blank, e.g. an empty parameter). An unrecognized token is left in the output with its braces so a typo is obvious in Preview instead of silently vanishing.
Reset sequence when this changesRestarts the counter every time the chosen field's value changes — rows are automatically grouped by that field first (then by your Order-by choice within each group), so interleaved sheets still get one clean reset per group rather than resetting on every row.
Sequence FormatNumber (1, 2, 3...), Padded Number (01, 02, 03... — set the digit count in Pad width), or Letters (A, B, C...). Pick a format and click Insert -> Number/Name to drop the matching token ({Serial}, {Serial|PADn}, or {Alpha}) into the rule at the cursor, without needing to know the token syntax by hand.
Extract SegmentSplits text on a delimiter and keeps one piece, counted from the Left (1st, 2nd, ...) or from the Right (1st, 2nd, ... counting backward from the end) — e.g. Split by "-", Right, Segment 1 keeps whatever comes after the last dash. Two ways to use it: Insert -> Number/Name drops it into the rule as a token ({SheetNumber|SPLIT:delim:n} / {SheetName|SPLIT:delim:n}), so it combines with {Serial}/{Alpha} and everything else in one Generate Preview — use this if you're also using a Sequence. Apply (bottom) instead overwrites the current staged New Number/New Name directly with just the extracted piece, discarding the rest of whatever's there (including a Sequence result already generated) — only use it for a one-off tweak after you're done with the rule.

Before you run it

  • Sheet Number and Sheet Name boxes must have the same number of lines (Normal Creation).
  • Column sorting is intentionally disabled in Super Sheet's grid so Move Up/Down works reliably — the list just starts sorted by Number from the initial scan.
  • Sheet Renamer skips placeholder sheets entirely (not scanned, not renamed) in this version.
  • Circular renames (e.g. A101→A102 and A102→A101 in the same batch) are handled safely — every Sheet Number change is staged through a temporary unique value first, so Revit never sees a mid-batch collision.
  • A Duplicate status blocks that row from Apply; it never overwrites the sheet already holding that number. Fix the rule, or edit the row's New Number directly, then re-check Status before applying.
  • Not built in this version (kept out to stay maintainable): Roman-numeral sequences, a parameter-name aliasing layer (use {Parameter:ActualName} directly), a different rule per group in one pass (filter, apply, change the filter, apply again covers this), a grid right-click menu, a standalone Parameter Inspector panel, and file-based logging (the pyRevit output window already gives a full per-row report every run).
