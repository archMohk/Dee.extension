CreatePack

DeeV.Template

Scan View Templates in this file and transfer selected ones to other open Revit documents in this session.

Risk level: Medium Overwrite mode deletes the existing same-named template in the target file first, then copies the source version in as a plain replacement (not a merged update) — make sure that's really what you want before choosing it.

What it does

Lists every View Template in the current file on the left, and every other Revit document open in the same Revit session (linked models excluded) on the right. Check any/all templates and any/all target files, then transfer — it copies the selected templates into each target using the same mechanism Revit's own cross-project copy/paste uses.

How to use it

  1. Open the other project file(s) you want to receive templates in the same Revit session first.
  2. Check the View Template(s) to send in the left grid.
  3. Check the target file(s) in the right grid (use Refresh Open Files if you opened one after starting the tool).
  4. Pick Skip Existing or Overwrite Existing for name collisions.
  5. Click Transfer Selected Template(s) to Selected File(s).

Options

Skip ExistingLeaves a same-named template in the target untouched.
Overwrite ExistingDeletes the existing template in the target, then copies the source version in as a replacement.

Before you run it

  • Only documents already open in the same Revit session show up as targets — open them first.
  • Linked models are excluded from the target list on purpose.
