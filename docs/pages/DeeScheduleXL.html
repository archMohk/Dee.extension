ExporterPack

DeeScheduleXL

Export Schedules to Excel (locked calculated cells, hidden Element Id per row) and re-import edited values back onto the matching elements.

Risk level: Medium Import writes values back onto real model elements — it checks a fingerprint per sheet so it only imports onto a Schedule whose structure hasn't changed since export, but always review the import results.

What it does

Three tabs:

  • Export — writes one Excel sheet per selected Schedule. Bidirectional mode adds a hidden Element Id column and locks calculated/non-settable cells so the file can be re-imported later; Unidirectional is a clean one-way copy only. Only itemized Schedules (one row per element) support Bidirectional.
  • Import — reads a previously-exported file, checks each sheet against the current model's Schedules (a fingerprint catches a Schedule that's changed structure since export), and writes edited (unlocked) cell values back onto the matching elements.
  • Live Editor — an in-tool Excel-like grid with copy/paste, so you can edit and push values back without ever leaving Revit.

How to use it

  1. Scan/Re-scan Schedules, check which ones to export, pick Bidirectional or Unidirectional, and Export to Excel.
  2. Edit the file in Excel (or use the Live Editor tab directly in Revit).
  3. Browse to the edited file on the Import tab — compatible sheets show on the left, incompatible ones (with a reason) on the right.
  4. Check the sheets to import and click Import.

Before you run it

  • Only itemized Schedules support round-trip (Bidirectional) editing — others export fine but can't be re-imported.
  • If a Schedule's structure changes after export (fields added/removed/reordered), that sheet becomes import-incompatible and is reported with a reason rather than silently mis-applied.
