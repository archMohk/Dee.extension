BatchPack

DeePublisher

Select Revit cloud files from ACC and batch-publish them. Supports Normal Publish (with links) and Publish without Links.

Risk level: Medium Publishing pushes the current server state to whatever consumes published models (e.g. Navisworks/BIM 360 viewers) for every file you check — there's no extra "are you sure?" confirmation beyond the file selection itself, so review the checked list before clicking Publish Selected.

What it does

Logs into ACC, lets you pick a Hub and Project, then check off files and publish them — this fires the same server-side publish command the ACC Docs "Publish" button uses, per file. It's an asynchronous request: success means the publish job was queued, not that it's already finished. This tool does not configure each file's Publish Settings itself (see DeeCoord for that) — it assumes the files are already set up to publish correctly.

How to use it

  1. Sign in to ACC, pick Hub → Project.
  2. Check which files to publish.
  3. Pick Normal Publish or Publish without Links.
  4. Click Publish Selected and review the colored results.

Before you run it

  • Make sure each file's Publish Settings are already configured correctly — this tool doesn't set them up.
  • Double-check the checked file list before publishing; there's no per-file undo once a publish job is queued.
