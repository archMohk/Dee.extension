BatchPack

DeeCoord

Create BIM Coordination views & publish set, sync, and publish.

Risk level: High Can Synchronize With Central (pushes to the shared model) and Publish, across many files, in one unattended run. It also drives the real Revit window via simulated ribbon clicks — don't touch the mouse/keyboard or switch windows while it's running.

What it does

The full pipeline version of DeeBIMview. For each selected cloud file, it can run up to 5 steps (each individually toggled on/off): Create/Update the Coordination + NAVIS 3D views, Configure Publish Settings, Synchronize With Central, Close After Sync, and Publish. The Publish Settings step actually drives Revit's real Collaborate > Publish Settings dialog via simulated clicks (there's no API for it) to create/select the named publish set and include the coordination view, then Save & Close. If that step fails for a file, its Publish step is automatically skipped so it doesn't publish an unconfigured set.

How to use it

  1. Sign in to ACC, pick Hub → Project, and select files (same as DeeBIMview).
  2. Confirm/edit the View Type, Coordination View, NAVIS View, and Publish Settings set names.
  3. Check which of the 5 steps to run for this batch.
  4. If Publish is enabled, pick Normal Publish or Publish without Links.
  5. Run it, and leave the Revit window alone until it finishes — it will visibly switch ribbon tabs and open/close a dialog for the Publish Settings step.
  6. Review the per-file, per-step colored results report.

Options

5 step togglesCreate/Update Views, Configure Publish Settings, Synchronize With Central, Close After Sync, Publish — all on by default, any can be turned off.
Publish modeNormal Publish (with links) or Publish without Links.

Before you run it

  • This is the highest-risk tool in the pack — it can push real changes to the shared central model and publish for many files in a single run. Double-check the file list and enabled steps before starting.
  • Because it drives the real Revit UI, don't use the mouse/keyboard on this machine or switch away from Revit while it's running — that can break the currently-running step.
