About

Update

Pull the latest version from GitHub and reload pyRevit to pick it up (a ribbon tab NAME change still needs a full Revit restart).

Risk level: None to your model This only affects the DeePack extension's own code on this PC — it never touches an open Revit project.

What it does

Opens a branded confirmation window; clicking Update Now runs pyrevit extensions update --all (pulling the latest version from GitHub, if this install was set up via pyrevit extend) and then reloads pyRevit to pick up the changes — the same reload mechanism as pyRevit's own built-in Reload button.

How to use it

  1. Click Update, then Update Now in the window that opens.
  2. Wait for the reload to finish.
  3. If a tab was renamed or a panel/button was restructured, a normal Reload sometimes isn't enough — fully close Revit, run pyrevit caches clear --all, then reopen Revit.
If a button or panel still looks wrong after updating: close Revit completely, run pyrevit caches clear --all from a terminal, then reopen Revit. Structural ribbon changes (new/renamed tabs, panels, or stacks) need this full cycle, not just Reload.
