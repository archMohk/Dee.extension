BatchPack

DeeS.Publish

Publish ALL Revit files in one or more selected ACC/BIM360 projects.

Risk level: Highest in the pack A single run can publish every Revit file across multiple entire projects — there's no per-file opt-out once a project is selected. Read the confirmation dialog's per-project file-count breakdown carefully before continuing.

What it does

Unlike DeePublisher (which picks individual files), this tool selects entire projects — every Revit file found in each selected project gets published, with no per-file picker at all. Before doing anything, it shows a confirmation listing a file-count breakdown per project (e.g. "ProjectA — 12 file(s), ProjectB — 5 file(s)") and the total, with explicit wording "This will publish ALL of them."

How to use it

  1. Sign in to ACC, pick a Hub.
  2. Check one or more Projects (not individual files).
  3. Read the confirmation breakdown carefully, then click Publish All (or Cancel).
  4. Pick Normal Publish or Publish without Links (applied to every file across every selected project).
  5. Review the colored results, grouped by [ProjectName] FileName.

Before you run it

  • Only select a project here if you genuinely want to publish every file in it — there is no way to exclude individual files within a selected project.
  • Use DeePublisher instead if you only want specific files published.
