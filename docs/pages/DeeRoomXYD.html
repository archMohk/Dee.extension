DeeRoomXYD

Scans every Room visible in the active view and reports its longest boundary edge along the X axis and its longest along the Y axis - and can place real Dimension elements for those two edges directly in the active view.

Risk level: Medium Scanning and reporting is entirely read-only. Place Dimensions in Active View is the one part of this tool that changes the model - it creates real Dimension elements. There's no separate confirm step beyond checking rows and clicking the button.

What it does

For every Room visible in the active view (not the whole document), DeeRoomXYD reads its real boundary segments (Room.GetBoundarySegments) rather than its bounding box. Each segment is measured by its true length and classified as running mainly along the model's X axis or its Y axis (by comparing how much its endpoints differ in X versus Y). The longest X-axis segment and the longest Y-axis segment found anywhere on the room's boundary - including any inner loops, like around a shaft or column - become that room's "Longest X Edge" and "Longest Y Edge".

This matters most for L-shaped or otherwise irregular rooms: a bounding box would report the full extent including the notch, while the longest real edge in each direction gives a more honest sense of the room's actual usable width and depth.

Check the rooms you want and click Place Dimensions in Active View to add real Dimension elements for those two edges - the same result as manually clicking Revit's Aligned Dimension tool on the walls at each end of the edge. This only works in a Floor Plan, Ceiling Plan, or Area Plan view.

How to use it

  1. Open DeeRoomXYD while a Floor Plan, Ceiling Plan, or Area Plan view is active - it scans automatically and lists every room visible in that view, with its longest X and Y edge lengths in your project's display units.
  2. Click column headers to sort - e.g. by Longest X Edge to find your widest rooms.
  3. Use Rescan Active View after switching views or editing room boundaries.
  4. Check the rooms you want dimensioned, then click Place Dimensions in Active View. Check the pyRevit output window afterward for how many dimensions were placed and which ones were skipped, and why.
  5. Export to Excel... saves the currently-scanned table for use outside Revit.

How dimension placement works

For a room's longest X (or Y) edge, DeeRoomXYD first checks the two boundary segments immediately before and after it in the same boundary loop for a usable wall face at each corner - the two clicks you'd make manually with Revit's Aligned Dimension tool. If either "official" neighbor isn't a plain wall (a short jog, a Room Separation Line with no solid geometry, a door/window right at the corner), it falls back to searching every Wall within roughly 15 ft of the room - not just touching it - and uses whichever wall's face is actually nearest that corner. If nothing usable is found at all, that one dimension is skipped and reported rather than guessed at.

The dimension line is drawn offset a small distance (about 6 in / 150 mm) from the wall, pulled toward the room's own center point - so it reads inside the room rather than sitting directly on top of the wall. This only shifts where the dimension line is drawn; the measured value always comes from the actual wall face References, so the offset never changes the number.

Options

Status column"OK" for rooms with a usable boundary; "Not Placed / Not Enclosed (zero area)" for rooms with no valid boundary at all (their Longest X/Y Edge show as "-"); "No usable boundary segments" in the rare case a room has area but no measurable straight/curved edges.
Select All / Select NoneChecks or unchecks every currently-listed room - only checked rooms are affected by Place Dimensions.

Before you run it

  • This is a brand-new button in an existing panel, so it needs a full Revit restart + pyrevit caches clear --all to appear the first time.
  • Only works in a Floor Plan, Ceiling Plan, or Area Plan view - in any other view type, the scan reports zero rooms and Place Dimensions is blocked.
  • X/Y here means the model's own internal X/Y axes (Project North), the same coordinate system every other geometry-reading tool in this extension uses - not True North and not a per-room rotated frame.
  • Placing dimensions runs in one Transaction across every checked room - Undo (Ctrl+Z) reverts the whole batch at once.
  • Try it on a couple of rooms first to see how it looks before running it across many at once.
