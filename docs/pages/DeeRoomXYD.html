LazyPack

DeeRoomXYD

Scans every Room and reports its longest boundary edge along the X axis and its longest along the Y axis - a read-only report, nothing in the model is ever touched.

Risk level: None Read-only - it only scans and reports. No Transaction, no element is ever moved, created, or deleted.

What it does

For every Room, DeeRoomXYD reads its real boundary segments (Room.GetBoundarySegments) rather than its bounding box. Each segment is measured by its true length and classified as running mainly along the model's X axis or its Y axis (by comparing how much its endpoints differ in X versus Y). The longest X-axis segment and the longest Y-axis segment found anywhere on the room's boundary - including any inner loops, like around a shaft or column - become that room's "Longest X Edge" and "Longest Y Edge".

This matters most for L-shaped or otherwise irregular rooms: a bounding box would report the full extent including the notch, while the longest real edge in each direction gives a more honest sense of the room's actual usable width and depth.

How to use it

  1. Open DeeRoomXYD - it scans automatically and lists every room with its longest X and Y edge lengths, in your project's display units.
  2. Click column headers to sort - e.g. by Longest X Edge to find your widest rooms.
  3. Use Rescan any time after editing room boundaries elsewhere.
  4. Export to Excel... saves the full table, including any flagged rooms, for use outside Revit.

Options

Status column"OK" for rooms with a usable boundary; "Not Placed / Not Enclosed (zero area)" for rooms with no valid boundary at all (their Longest X/Y Edge show as "-"); "No usable boundary segments" in the rare case a room has area but no measurable straight/curved edges.

Before you run it

  • This is a brand-new button in an existing panel, so it needs a full Revit restart + pyrevit caches clear --all to appear the first time.
  • X/Y here means the model's own internal X/Y axes (Project North), the same coordinate system every other geometry-reading tool in this extension uses - not True North and not a per-room rotated frame.
  • This reports lengths only - it does not create Dimension annotations in any view.
