HealthPack

DeeCleaner

Find and clean up zero-area rooms, in-place families, unused Model/Detail Groups, unplaced views, and empty sheets.

Risk level: Medium The Delete actions on each tab are real, permanent deletions once confirmed — review the checked rows before clicking Delete Selected.

What it does

Five independent cleanup scans over the whole project, each its own tab:

  • Zero-Area Rooms — Rooms with Area ≤ 0 (typically Unplaced or Not Enclosed). List + Delete Selected.
  • In-Place Families — every in-place family instance with its category/level/location. List + Isolate Selected in 3D View (creates a dedicated 3D view and temporarily isolates just those elements via Revit's own Temporary Hide/Isolate).
  • Unused Groups — Model Group / Detail Group types with zero placed instances anywhere in the project. List + Delete Selected.
  • Views — every View (Sheets excluded), flagged Yes/No whether it's placed on any Sheet. "Select All Not On Sheet" is a one-click shortcut to the usual cleanup candidates. List + Delete Selected.
  • Sheets — every Sheet, flagged Yes/No whether it contains any View/Schedule. "Select All Empty Sheets" shortcuts to the usual cleanup candidates. List + Delete Selected.

How to use it

  1. Click Scan Project — this populates all five tabs at once.
  2. Switch to the tab you want to act on.
  3. Check the rows to act on (Select All, Select Highlighted, or the tab's shortcut button all help here), or use Isolate for In-Place Families.
  4. Click Delete Selected (or Isolate Selected in 3D View) and confirm.

Before you run it

  • Deleting a Sheet removes it and its placed Viewports, but the underlying Views themselves survive (they just become unplaced) — run the Views tab afterward if you also want to clean those up.
  • "Isolate in 3D View" uses Revit's Temporary Hide/Isolate — it's session-only until you make it permanent or reset it from the View Control Bar.
