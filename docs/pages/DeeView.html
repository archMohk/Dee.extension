CreatePack

DeeView

Batch-create views (Floor/Ceiling/Structural/Area plans) for selected levels, with templates, scales, naming, and optional sheet placement.

Risk level: Low Only creates new views/sheets in the current document — nothing is deleted, and it's all one Transaction (undoable).

What it does

A 3-step wizard for generating a batch of views in one pass instead of creating each one by hand:

  • Step 1 — Levels: check which Levels to seed new view rows with (search box included for large level lists).
  • Step 2 — Views: a table of view "definitions" to create — each row has its own View Type, View Template, Scale, Prefix/Suffix naming, and a Place on Sheet toggle, and its own list of Levels (Pick Levels for Selected Row(s) lets different rows target different levels). Preview Naming shows exactly what every resulting view name will be before you create anything.
  • Step 3 — Sheets: options for placing the newly created views onto sheets automatically.

A Presets toolbar at the top lets you save/load/import/export your whole Step 2 configuration as JSON, so a naming/template setup can be reused across projects.

How to use it

  1. Check the Levels you want in Step 1 (or skip and add levels per-row later).
  2. In Step 2, Add Row for each kind of view you want, set its View Type/Template/Scale/Prefix/Suffix, and assign Levels to it.
  3. Click Preview Naming to sanity-check the resulting names.
  4. Move to Step 3 if you want views placed on sheets automatically.
  5. Generate. Optionally save your Step 2 setup as a Preset first if you'll reuse it.

Before you run it

  • Check the Preview Naming output before generating — a naming clash (duplicate resulting name) is easier to fix before creation than after.
