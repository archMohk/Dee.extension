ExporterPack

DeePrinter

Batch-export selected sheets to PDF, DWG and/or DXF, with custom naming and a drag-and-drop parameter-based folder hierarchy.

Risk level: Low Only writes export files to disk — the model itself is never changed.

What it does

Lists every sheet in the project (with a filter box), lets you check which ones to export, then builds the output file name from tokens you arrange (date, time, sheet number/name, and more) and an optional folder hierarchy built from sheet parameters (drag parameters into an ordered list, top = outermost folder). Exports to PDF, DWG, and/or DXF in one pass.

How to use it

  1. Filter and check the sheets you want to export.
  2. Build the file name pattern by dragging tokens (or using the Add/Remove/Move buttons) into the naming sequence, then Preview it.
  3. Optionally build a folder hierarchy from sheet parameters the same way, and Preview Path.
  4. Pick an Output Folder.
  5. Check Export PDF/DWG/DXF as needed, then run Export Selected.

Before you run it

  • Characters not allowed in filenames are stripped automatically, so previewing the name/path first is the fastest way to confirm it'll look right.
