BatchPack

DeeLinkReview

Batch-scan files for shared linked models, pick one, and open Coordination Review for it (you review/accept/reject yourself).

Risk level: Low Only opens files and a native Revit dialog for you — every Accept/Reject/Postpone decision stays entirely in your hands.

What it does

Scans a batch of cloud files (opening and closing each in turn) to find which linked models are shared across them, then shows a summary like "LinkedModel.rvt (in 3/5 files)". You pick one linked model to review; if more than one host file in the batch references it, you then pick which host file to open. The tool opens that file and drives Revit's Collaborate > Coordination Review dialog open for you — then explicitly tells you to make the Accept/Reject/Postpone decision yourself, since there's no safe API to automate that.

How to use it

  1. Sign in to ACC, pick Hub → Project.
  2. Check which files to scan, click Scan Selected.
  3. Pick the shared linked model you want to review from the summary.
  4. If needed, pick which host file to open it in.
  5. Make your Accept/Reject/Postpone decision in the Coordination Review dialog that opens (or open it yourself via Collaborate > Coordinate > Coordination Review if it couldn't be opened automatically).

Before you run it

  • Needs at least one selected file that actually contains linked RVT models — otherwise it reports nothing found.
  • As with DeeCoord, the dialog-opening step drives the real Revit window — avoid interacting with the machine while it's mid-scan.
