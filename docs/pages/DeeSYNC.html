BatchPack

DeeSYNC

Synchronizes every workshared Revit model currently open in this session.

Risk level: High There is no file picker and no per-file confirmation — picking "Sync Only" or "Sync and Close" immediately synchronizes every open workshared model in the session in one go. Make sure you actually want to sync all of them before choosing.

What it does

No ACC login and no file browsing — this works purely on whatever's already open in the current Revit session. You pick "Sync Only" or "Sync and Close", and every open, workshared, non-linked, non-family document gets a full Synchronize With Central (comment "Batch sync - all open models", relinquishing all worksets). Non-workshared open documents are skipped and reported as such.

How to use it

  1. Make sure only the models you actually want synced are open in this Revit session (there's no per-file picker).
  2. Run the tool and choose Sync Only or Sync and Close.
  3. Review the plain-text OK/FAILED/SKIPPED list per document.

Before you run it

  • Close any open model you don't want synced before running this — there's no way to exclude one afterward.
  • Synchronize With Central pushes to the shared central model, visible to every collaborator.
  • If nothing workshared is open, the tool simply does nothing (no "nothing found" alert) — don't assume a run happened just because no error appeared.
