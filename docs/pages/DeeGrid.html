CreatePack

DeeGrid

Scan project Grids (Vertical/Horizontal) into editable tables with a live 2D previewer — rename, reposition, add, or delete grids and apply the changes to the model in one batch.

Risk level: Low Nothing changes in the model until you apply your edits, and it's all one Transaction (undoable).

What it does

Scans every Grid in the project and splits them into Vertical and Horizontal tables, each with a live 2D previewer showing spacing. You can rename grids (batch pattern-based renaming), reposition/respace them by editing the dimensions directly, add new grids, or delete existing ones — then apply everything in one batch instead of editing each grid one at a time in Revit's own UI.

How to use it

  1. Open the tool — it scans and lists the project's Grids in the Vertical/Horizontal tables.
  2. Use the previewer to check current spacing, then edit names/positions directly in the table, or use the batch-rename pattern option.
  3. Add or remove rows for grids you want created or deleted.
  4. Apply the changes to push everything to the model in one go.
  5. Optionally export the grid list to CSV for a record/Excel handoff.

Before you run it

  • Review the live preview before applying — repositioning grids affects anything dimensioned or hosted to them.
