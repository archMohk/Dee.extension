LazyPack

DeeW.Batch Save to Cloud

Bulk-converts hundreds of local Revit models into Autodesk Construction Cloud Cloud Models, with a fully automatic dialog-suppressed pipeline optimized for very large batches.

Risk level: High Designed to run fully unattended across potentially hundreds of files: every dialog is auto-resolved and nothing pauses for confirmation, including before detach/worksharing/upload. This is the highest blast-radius tool in the extension — always test on a small batch of backup/non-production files first.

What it does

Same core pipeline as DeeW.Sharing (shares all of its underlying services), but built for scale: only one Revit Document is ever open at a time, and it's closed and released immediately after each file so processing hundreds of models doesn't exhaust memory. Each file's upload mode is auto-detected from its type:

  • Mode 1: Local RVT → ACC Cloud Model
  • Mode 2: Central RVT → Detach → ACC Cloud Model
  • Mode 3: Local Copy of Central → Detach → ACC Cloud Model

Every dialog Revit can show (missing links/families, upgrade notices, duplicate types, save warnings, etc.) is auto-resolved so the batch never blocks; any per-file error is logged and the batch continues to the next file rather than aborting.

How to use it

  1. Browse to a source folder (optionally including subfolders) and click Scan Folder.
  2. Select the models to process; check the Upload Mode column to see what each one will do.
  3. Pick your ACC destination and set your options.
  4. Click Run Batch and let it work through the list — the Log & Report tab shows live progress (current file, current step, elapsed/ETA, success/fail/skip counts).
  5. Use Export Report for a full Excel/CSV/TXT record.

Options

Skip / Overwrite Existing / Rename DuplicatesHow to handle a cloud model that already has the target name. Overwrite does not delete/replace the existing cloud item (an unverified, destructive API call this tool doesn't perform) — it skips the file instead, clearly noted in the report.
Delete Local BackupDeletes Revit's own auto-generated "<name>.####.rvt" backup files next to the source file after a successful upload — never the source file itself.
Enable Worksharing / Detach Automatically / Audit / Compact / Open All WorksetsSame as DeeW.Sharing.
Automatically Resolve DialogsOn by default for this tool, since a batch of hundreds of files must never stop on a modal prompt.

Before you run it

  • This is a brand-new dropdown (DeeW.Cloud) with brand-new buttons, so it needs a full Revit restart + pyrevit caches clear --all to appear the first time.
  • Runs under pyRevit's CPython 3 engine, new ground for this extension — see DeeW.Sharing's handbook page for the full explanation.
  • Make sure Revit itself is signed in to your Autodesk account — the actual cloud upload needs that, separately from ACC browsing.
  • Test on a small batch of backup/non-production files first, especially given how automatic and unattended this tool is by design.
