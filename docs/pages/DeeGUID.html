RevitInfo

DeeGUID

Diagnostic only — prints the active cloud document's real project/model GUIDs so they can be compared against what the ACC tools compute.

Risk level: None Fully read-only/diagnostic — prints information only, never changes anything.

What it does

This is a developer/diagnostic tool, not a day-to-day production tool. With a cloud (ACC/BIM360) model open and active, it reads the document's real Project GUID / Model GUID / Region directly from Revit, then searches your accessible hubs/projects for a matching item by filename and tries several GUID-decoding strategies against the ACC API's data, printing each candidate next to a MATCH/mismatch tag against the real values. It exists to help verify the GUID-resolution logic the other batch tools (DeeOpener, DeeCoord, etc.) rely on internally.

How to use it

  1. Open a cloud model via File > Open > Cloud Model, and make sure it's the active document.
  2. Run the tool — it prints a diagnostic report straight to the pyRevit output window, ending with a summary of the real target GUIDs.

Before you run it

  • The active document must already be an open cloud model, and it needs to be findable by exact filename match in one of your accessible ACC hubs.
  • Most users won't need this day-to-day — it's here for troubleshooting the ACC-related tools if one of them ever behaves unexpectedly.
