BatchPack

DeeLINK

Browse your ACC/BIM360 project, pick multiple Revit files, and batch-link them into the active document. Choose from 4 positioning methods.

Risk level: Low-Medium Adds link instances to the currently open model in-session — not destructive, but double-check the active document is the right one before running, and remember to Sync afterward if the links should be shared.

What it does

Logs into ACC, lets you pick a Hub and Project, then check off which cloud Revit files to link into your currently active document — all in one batch, using whichever positioning method you choose.

How to use it

  1. Open the project document you want to link into, and make sure it's the active document.
  2. Sign in to ACC, pick Hub → Project.
  3. Check which files to link.
  4. Pick a positioning method.
  5. Run — review the results, then Sync the active document if the links should be visible to others.

Options

Positioning methodAuto - Center to Center, Auto - Internal Origin to Internal Origin, Auto - By Shared Coordinates, or Auto - Project Base Point to Project Base Point. Applied identically to every file linked in that run.

Before you run it

  • Requires an already-open, non-family project document to be active — the tool alerts and stops if none is open.
