DeeAlign

DeeAlign

AutoCAD-style Align/Distribute for ordinary Revit model and annotation elements - not sheets or viewports (that's DeeAligner). Select elements in any view, then click one of the 7 buttons below.

Risk level: Medium Every button acts immediately on the current selection, in one Transaction, with no preview step - a single Undo reverts the whole batch. There is no separate Apply/confirm dialog before the move (only Distribute warns you if you haven't selected enough elements).

The 7 buttons

Align LeftMoves every other selected element so its BoundingBox Min.X matches the reference element's Min.X.
Align RightSame, using Max.X.
Align CenterSame, using each element's horizontal BoundingBox center.
Align TopSame, using Max.Y.
Align BottomSame, using Min.Y.
Distribute HorizontalRequires 3+ elements. Sorts by X center, keeps the leftmost and rightmost fixed, and spaces everything in between equally by center X.
Distribute VerticalSame as above, sorted/spaced by Y center instead.

How to use it

  1. Select the elements to align/distribute in any view - the first element you select is always the reference that the others move to match (for Align Left/Right/Center/Top/Bottom). For Distribute, the selection order doesn't matter - the tool sorts by position itself and keeps the outermost two fixed.
  2. Click the matching button in the DeeAlign panel.
  3. Read the summary dialog: elements moved, elements skipped, and how long it took.
  4. If anything was skipped, a detailed report opens listing each skipped element and why (pinned, in a group, owned by another user, no bounding box, etc.) - nothing ever stops the batch, unsupported elements are simply skipped and reported.

What it supports

As many movable element types as possible, rather than a fixed category list: Family Instances (Furniture, Casework, Planting, Lighting Fixtures, Mechanical Equipment, Generic Models, Detail Components), Model Groups, Text Notes, Tags, Annotation Symbols, Filled Regions, Images, CAD Imports, and anything else with a usable BoundingBox. Only translation is ever used (ElementTransformUtils.MoveElement) - rotation and geometry are never touched, so curve-based elements (walls, beams, etc.) keep their exact orientation.

Skipped automatically, with a reason shown in the report: pinned elements, elements that are members of a Group (select/move the Group itself instead), elements owned by another user in a workshared model, linked-model instances, and anything without a resolvable bounding box.

Options / behavior notes

Reference elementAlways the first element you selected, for every Align button. (The underlying engine is built so a future version could offer Last Selected / Largest / Smallest / Manually Picked instead - not exposed yet.)
Align axisLeft/Right/Center only ever move elements along X; Top/Bottom only ever move them along Y. Elevation (Z) is never changed.
Distribute minimumNeeds at least 3 selected elements - fewer shows "Please select at least 3 elements." and does nothing.
Annotation elementsText Notes, Tags, Filled Regions, and other view-specific elements only report a bounding box relative to the view they're placed in - DeeAlign reads it from your current active view, so make sure you're working in the view where they're actually placed.

Before you run it

  • This is a brand-new panel, so it needs a full Revit restart + pyrevit caches clear --all to appear the first time.
  • Only the core 5 Align + 2 Distribute commands are implemented so far. Align to View Center/Level/Grid/Work Plane/Reference Plane, Match Rotation/Elevation/Offset, Equal Edge/Gap Distribution, Circular/Polar Distribution, Align Along Curve/Path, Arrange in Grid/Matrix, Auto Stack, Mirror and Align, and the by-Origin/Insertion-Point/Geometry-Center align variants are on the roadmap but not built yet - the shared engine (lib/dee_align_service.py) is structured so each can be added later as one function, without touching the buttons already built.
  • Each command runs in one Transaction across the whole selection - Undo reverts everything from that click at once, not element-by-element.
  • Try it on a handful of elements first to confirm which axis moves which way before running it on a large selection.
