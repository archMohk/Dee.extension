DeeW.Cloud — Coming Soon

Eight DeeW.Cloud tools are scaffolded in the dropdown but not implemented yet. Clicking any of them shows a "Coming Soon" dialog. They'll share the same reusable services as DeeW.Sharing and DeeW.Batch Save to Cloud when built.

Risk level: None Every one of these just shows an informational dialog and does nothing else.

DeeW.Publish

Will publish ACC/BIM360 cloud models for review, reusing DeeW.Cloud's shared cloud service and model scanner.

DeeW.Consume

Will consume (link/import) published cloud content into the active project.

DeeW.Transfer

Will transfer standards, views, or settings between local and cloud models.

DeeW.Batch Upgrade

Will batch-upgrade a folder of local or cloud models to a target Revit version.

DeeW.Audit

Will batch-audit local and cloud models and report health/corruption issues.

DeeW.Clean

Will batch-clean local and cloud models (purge, compact, remove unused elements).

DeeW.Sync

Will batch-synchronize workshared cloud models with detailed reporting.

DeeW.Package

Will package a project (model + links + families) for archival or handoff.
