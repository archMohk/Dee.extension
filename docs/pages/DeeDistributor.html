ModelingPack

DeeDistributor

Auto-distribute family instances across room/space boundaries using configurable patterns, spacing, alignment, rotation, and collision detection.

Risk level: Low Only places new family instances — it's all one Transaction (undoable), and nothing existing is deleted or moved.

What it does

Places a chosen family (e.g. ceiling lights, floor outlets, columns) automatically across one or more Rooms/Spaces, following a pattern (uniform grid, single row, etc.) with configurable spacing, alignment, and rotation. It also has a Lighting Distribution mode with automatic spacing calculated from room area. Collision detection avoids overlapping existing elements, and spacing/instance-count safety guards keep a mis-typed tiny spacing value from generating an absurd number of instances.

How to use it

  1. Step 1: pick the source — selected Rooms/Spaces, the active view, or the whole project — and scan.
  2. Check which Rooms/Spaces to distribute into.
  3. Step 2: pick the Category, Family, and Type to place, and configure the distribution pattern, spacing, and hosting.
  4. Step 3: review the instance-count estimate and preview, then generate.

Before you run it

  • Check the instance-count estimate in Step 3 before generating on a large room set with tight spacing — it's there specifically to catch runaway counts before they happen.
