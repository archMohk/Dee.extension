CreatePack

DeeLEVEL

Scan project levels into an editable grid — rename, move, add, or delete levels, then apply the changes to the model in one batch.

Risk level: Low Nothing changes in the model until you apply your edits, and it's all one Transaction (undoable).

What it does

Scans every Level in the project into one editable grid, showing name and elevation. Instead of editing each Level one at a time in Revit's own Properties/Project Browser, you can rename, reposition (move up/down), add new Levels, or delete existing ones, review everything in one table, then apply it all in a single batch.

How to use it

  1. Open the tool — it scans and lists the project's Levels.
  2. Edit names and elevations directly in the grid, or use the batch-scope/naming tools to apply to several rows at once.
  3. Add or remove rows for Levels you want created or deleted.
  4. Apply the changes to push everything to the model in one go.
  5. Optionally export the level list to CSV for a record/Excel handoff.

Before you run it

  • Moving/renaming a Level affects every view, schedule, and hosted element tied to it — review the grid carefully before applying.
