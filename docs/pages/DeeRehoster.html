HealthPack

DeeRehoster

Scan every Level's hosted elements, report/export them, color-code them in a new 3D view, and optionally rehost them to a different Level.

Risk level: Medium Rehosting changes an element's Level parameter (and, for Base+Top style elements, shifts its offsets to compensate) — review the scan/report before applying to a large scope.

What it does

Scans elements by Level, lets you review/export the results, builds a color-coded 3D view (one color per Level) so mis-hosted elements are visually obvious, and lets you rehost elements — either a manual selection/category scope, or automatically via Fix Mis-Hosted Elements, which detects elements whose Level parameter doesn't match their true physical elevation and corrects the Level (nothing physically moves) while building a "DeeRehoster - Corrected Elements" view showing just what got fixed.

How to use it

  1. Scan the model to build the Level/element list.
  2. Review the color-coded 3D view to spot obviously mis-hosted elements.
  3. Either manually pick a category/selection scope and a target Level to rehost, or click Fix Mis-Hosted Elements to let it detect and correct mismatches automatically.
  4. Review the results report and the "Corrected Elements" view afterward.

Before you run it

  • Fix Mis-Hosted Elements only changes the Level parameter to match physical elevation — it does not move geometry.
  • Review the scan report before rehosting a broad scope; some elements may be intentionally hosted differently from their raw elevation.
