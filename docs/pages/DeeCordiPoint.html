LazyPack

DeeCordiPoint

Isolate Levels, Site, Project Base Point, Survey Point, and Internal Origin in a dedicated 3D view — relocate a far-away Survey Point without touching North/South, export point coordinates, list linked models' coordinate info, and apply the coordinate system (Acquire Coordinates, Angle to True North, Project/True North view toggle).

Risk level: Medium Relocate Survey Point moves a real coordinate reference element (un-clip → move → re-clip), and the Coordinate System tab edits the Project Base Point's Angle to True North and the active view's orientation. None of these change the Survey Point's real-world coordinate value — but it's still worth understanding before you click on a live project.

What it does

Points tab — Creates (or reuses) a 3D view named DeeLazy Coordinates View and isolates Levels, Site, the Project Base Point, Survey Point, and Internal Origin in it, so you can see exactly where your project's coordinate reference points sit relative to the model. The Key Points grid (Internal Origin & Survey Point) and the separate Project Base Point grid each show X/Y/Z plus the shared coordinates — North/South, East/West, Elevation — along with Angle to True North and Clipped state. The distance readout below Key Points shows how far apart the Survey Point and Internal Origin are, both as a total distance and as per-axis dX/dY/dZ.

Unclip Survey Point / Clip Survey Point let you toggle the Clipped state directly and manually — unclipped, you can drag the Survey Point yourself in Revit and only the point moves (not the model); clipped (the default) protects it from accidental drags. Separately, if the Survey Point is far away (a common cause of Revit accuracy/rendering issues once real-world survey coordinates are acquired), Relocate Survey Point un-clips it, moves it to coincide with either the Internal Origin or the Project Base Point, then re-clips it — its real-world coordinate value doesn't change, only its on-screen distance from the model. The Project Base Point's Angle to True North is captured before this cycle and restored afterward if it changed at all, so relocating the Survey Point can never silently affect North/South orientation.

You can also Export Points to Excel (both tables together), and Scan Linked Models to list every linked model's placement origin relative to the host (plus that link's own Project Base Point/Survey Point if it's currently loaded), also exportable.

Coordinate System tab — Acquire Coordinates lists every Revit link and linked CAD file in the project; pick one and click Select in Revit to pre-select it, then run Manage tab > Coordinates > Acquire Coordinates yourself — Revit does the actual coordinate math, this tool just saves you the manual pick. Angle to True North lets you read/set the Project Base Point's angle directly, in degrees. Active View Orientation switches the active Plan/Site view between Project North and True North.

How to use it

  1. Click Create/Update Coordinates View — review the Key Points grid, the Project Base Point grid, and the distance readout.
  2. If you want to reposition the Survey Point yourself in Revit, click Unclip Survey Point first, drag it, then click Clip Survey Point again when done.
  3. Set a Distance Threshold if you want a warning when the Survey Point is farther than that from the Internal Origin.
  4. If needed, click Relocate Survey Point to Internal Origin or ...to Project Base Point, and confirm.
  5. Use Export Points to Excel for a record of both tables.
  6. Click Scan Linked Models to see every link's coordinate info, and export that too if needed.
  7. Switch to the Coordinate System tab: pick a link and click Select in Revit, then run Acquire Coordinates from the Manage ribbon tab yourself.
  8. Edit the Angle to True North field and click Apply if you need to set it directly.
  9. Use Set Active View to Project North / True North to flip the current plan/site view's orientation.

Options

Unclip / Clip Survey PointToggles the Clipped parameter directly, so you can drag the Survey Point yourself in Revit (unclipped moves only the point, not the model) and re-lock it afterward.
Distance ThresholdShown in your project's display unit; triggers a warning after building the view if the Survey Point exceeds it.
Relocate targetInternal Origin or Project Base Point — pick whichever you want the Survey Point to sit on top of. North/South orientation is preserved either way.
Acquire Coordinates targetAny Revit link or linked (non-embedded) CAD import in the project — only pre-selects it, doesn't run Acquire Coordinates itself.
Angle to True NorthDegrees, applied directly to the Project Base Point's own parameter.
Active View OrientationProject North or True North, applied to the active view only (Plan/Site views).

Before you run it

  • This button's panel already exists on the ribbon, so this update needs only a Reload from pyRevit — no restart or cache clear required.
  • A linked model's own Project Base Point/Survey Point only show up if that link is currently loaded (not unloaded/missing).
  • The Active View Orientation toggle only works on Plan/Site views that expose an Orientation parameter.
