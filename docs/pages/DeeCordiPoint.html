LazyPack (CoordinatePack)

DeeCordiPoint

Isolate Levels, Site, Project Base Point, Survey Point, and Internal Origin in a dedicated 3D view — relocate a far-away Survey Point, export point coordinates, and list linked models' coordinate info.

Risk level: Medium Relocate Survey Point moves a real coordinate reference element (un-clip → move → re-clip). It doesn't change the Survey Point's real-world coordinate value, only its on-screen distance from the model — but it's still worth understanding before you click it on a live project.

What it does

Creates (or reuses) a 3D view named DeeLazy Coordinates View and isolates Levels, Site, the Project Base Point, Survey Point, and Internal Origin in it, so you can see exactly where your project's coordinate reference points sit relative to the model. The Key Points grid shows each point's X/Y/Z, Angle to True North, and Clipped state, plus how far the Survey Point is from the Internal Origin.

If the Survey Point is far away (a common cause of Revit accuracy/rendering issues once real-world survey coordinates are acquired), Relocate Survey Point un-clips it, moves it to coincide with either the Internal Origin or the Project Base Point, then re-clips it — its real-world coordinate value doesn't change, only its on-screen distance from the model.

You can also Export Points to Excel, and Scan Linked Models to list every linked model's placement origin relative to the host (plus that link's own Project Base Point/Survey Point if it's currently loaded), also exportable.

How to use it

  1. Click Create/Update Coordinates View — review the Key Points grid and the distance readout.
  2. Set a Distance Threshold if you want a warning when the Survey Point is farther than that from the Internal Origin.
  3. If needed, click Relocate Survey Point to Internal Origin or ...to Project Base Point, and confirm.
  4. Use Export Points to Excel for a record.
  5. Click Scan Linked Models to see every link's coordinate info, and export that too if needed.

Options

Distance ThresholdShown in your project's display unit; triggers a warning after building the view if the Survey Point exceeds it.
Relocate targetInternal Origin or Project Base Point — pick whichever you want the Survey Point to sit on top of.

Before you run it

  • This is a brand-new ribbon tab, so it needs a full Revit restart + pyrevit caches clear --all to appear the first time — a plain Reload isn't enough.
  • A linked model's own Project Base Point/Survey Point only show up if that link is currently loaded (not unloaded/missing).
