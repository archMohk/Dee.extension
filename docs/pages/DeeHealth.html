HealthPack

DeeHealth

Import an Excel QC rubric (section/test weights + thresholds), run ~40 model health checks, and compute a weighted overall health score.

Risk level: None Every check only reads the model — nothing is ever changed.

What it does

Runs the firm's QC rubric (45 weighted tests across sections like Model Performance, External Files, Project Settings, Views, Datum, and naming conventions) against the open project and produces a single weighted Overall Score, plus a PASS/FAIL against a configurable approval limit, and a plain-English auto-generated summary. Opens with a built-in default rubric already loaded, so it works immediately without needing an Excel file — Import Rubric from Excel lets you swap in a different/updated workbook.

How to use it

  1. Configuration tab: optionally Import Rubric from Excel, adjust Weight/E/F/G thresholds per test, set the Approval Limit, and use the per-test or per-section Run checkboxes to skip tests you don't need (also cuts run time on a large project).
  2. Click Run Health Check.
  3. The Results tab shows the Overall Score, PASS/FAIL, the auto-summary, and every test's individual status (color-coded row by row).
  4. Export the report to a themed 2-sheet Excel workbook (Summary + Detailed) if you need to hand it off.

Options

Run checkbox (per test/section)Skip tests that don't apply, or that are slow on a large project.
Weight / E (good) / F (warn) / G (fail)Editable thresholds per test, tuned to the firm's own QC rubric.
Approval Limit (%)The Overall Score cutoff for PASS vs FAIL.
Naming Pattern (regex)Used by the naming-convention checks.

Before you run it

  • Some checks (e.g. views not on sheets) can be slow on very large models — use the Run checkboxes to narrow scope if a full run is too slow.
