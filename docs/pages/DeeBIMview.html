BatchPack

DeeBIMview

Open Revit files and create the BIM Coordination + NAVIS 3D views (no sync, no publish).

Risk level: Low Creates 3D views only. Files are left open, unsynced — nothing is pushed to the shared model.

What it does

Logs into ACC/BIM360, lets you pick a Hub and Project, then check off which cloud Revit files to process. For each selected file, it opens it directly from the cloud and creates (or reuses) two 3D views — a "BIM Coordination View" and a "BIM Exported NAVIS" view, both hiding the RVT Links category so linked models don't clutter them. Files are left open afterward for you to review, sync, or publish manually.

How to use it

  1. Sign in to ACC when prompted (cached for about an hour after).
  2. Pick a Hub, then a Project.
  3. Use the cached file list or rescan.
  4. Check which files to process, and pick an Open mode (Regular, or All Worksets Closed).
  5. Confirm/edit the View Type, Coordination View, and NAVIS View names.
  6. Run — review the colored results, then sync/publish/close the opened files yourself.

Options

Open modeRegular Open (all worksets) or Open with All Worksets Closed.
View/Type namesEditable defaults for the 3D View Type, Coordination View, and NAVIS View.

Before you run it

  • Requires acc_config.json and valid ACC/BIM360 access to the target hub/project.
  • The file list can be a cached snapshot from a previous run — rescan if you know the project's files have changed recently.
  • This tool intentionally does not sync/publish/close — do that yourself afterward.
