DeePack Handbook

One page per button on the DeePack ribbon tab — what it does, how to use it, and what to watch out for. Grouped by panel, in the same order they appear on the ribbon. Tools without a page yet are listed with a short description only.

Read this first: DeeAI is the highest-risk tool in this handbook DeeAI lets an AI chat assistant write and immediately run code against your open document - by explicit design, with no per-action confirmation dialog. Every other tool below asks first, or at least tells you exactly what it's about to do before it does it; DeeAI does not. Only the Undo stack protects you. Read its page before trying it.
Read this first if you're new to the Session and Cloud tools Several Session and Cloud tools can Synchronize With Central or Publish across many files in one run, with little or no per-file confirmation. Ranked by blast radius: DeeS.Publish (publishes every file in whole projects) > DeeSYNC (syncs every open model, no file picker) > DeeCloseAll's Relinquish mode > DeePublisher > everything else (opens/links/reads only).

Low
DeeSYNC

High

DeeCloseAll
Close open documents: Sync & Close, Relinquish & Close, or Close without Relinquish.
High*
