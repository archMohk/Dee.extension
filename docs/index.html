DeePack Handbook

One page per button on the DeePack ribbon tab — what it does, how to use it, and what to watch out for. Grouped by panel, in the same order they appear on the ribbon.

Read this first if you're new to the BatchPack tools Several BatchPack tools can Synchronize With Central or Publish across many files in one run, with little or no per-file confirmation. Ranked by blast radius: DeeS.Publish (publishes every file in whole projects) > DeeSYNC (syncs every open model, no file picker) > DeeCoord and DeeCloseAll's Relinquish mode > DeePublisher > everything else (opens/links/reads only).

BatchPack panel — ACC/BIM360 batch operations

DeeBIMview
Batch-open cloud files and create BIM Coordination/NAVIS views (no sync/publish).
Low
DeeCloseAll
Close open documents: Sync & Close, Relinquish & Close, or Close without Relinquish.
High*
DeeCoord
Full pipeline: create views, configure publish settings, sync, close, publish.
High
DeeLINK
Batch-link cloud files into the active document with 4 positioning methods.
Low-Med
DeeLinkReview
Find shared linked models across files and open Coordination Review for one.
Low
DeeOpener
Batch-open ACC/BIM360 cloud files by checkbox.
Low
DeePublisher
Batch-publish selected cloud files.
Medium
DeeS.Publish
Publish ALL files in one or more entire selected projects.
Highest
DeeSYNC
Synchronize every workshared model open in this session — no file picker.
High
