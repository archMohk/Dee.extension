Scope: all 16 panels / ~100 buttons in `DeePack.tab`, `lib/` (31k lines), `startup.py`, installer, CI. Read-only review; nothing run in Revit.

## D. Major updates (ranked)

### 1. `lib/dee_ui.py` — one UI kit, delete 140+ copies
- `SafeProgress` (cancel, RDP-safe), `pump()`, `eid_int()`, `require_doc()`, `run_in_group(doc, name, fn)` (TransactionGroup + Assimilate + rollback on cancel).
- Branded `message / confirm / error / result` dialogs replacing `forms.alert` + `MessageBox.Show`; `pick_folder/pick_file` wrappers (pyRevit forms, not WinForms).
- `log.warn()` + per-run "N succeeded / N skipped (why)" summary dialog replacing `except: pass`.

### 2. Finish the theme (current branch)
- Keep `theme=True` default. Add a dark variant to `DeeTheme.xaml` and let the 4 dark tools (DeeInitiator, DeeSuperLINK, DeeMAPLink, DeeSVTemplate) use it instead of `theme=False`.
- Pick one window class: fold DeeRoundedWindow's title bar + light/dark toggle into DeeBrandedWindow, add a "?" button → `help_url`.
- Convert popup-chain tools to one window each: DeeOpener, DeePublisher, DeeLINK, DeeCloseAll, DeeCtotopo, DeeDropToSurface, DeeLinkReview, DeeCoord.

### 3. Startup & network
- Access check: 3–5 s timeout, cache 24 h, offline grace; never block Align/WebSite.
- Startup pull: background thread, once per day, Dee only (or opt-in).
- Pollers: background thread + ExternalEvent for toasts.

### 4. Ribbon cleanup
- Remove 7 stubs; move DeeGUID under About; merge per §C; fix `context:` values; `context: selection` on Align; short tooltips + `help_url` + highlight.
- DeeControl: store state in `%APPDATA%\Dee\control.json`, apply via `RibbonItem.Enabled` at startup.

### 5. Security & trust
- DeeAI: "approve before run" toggle showing generated code; keys via DPAPI in `%APPDATA%` (not OneDrive-synced `lib/.deew_settings`).
- DeeMCP: token to `%APPDATA%`; read-only mode.
- Telemetry: opt-out + disclosure (collects email, username, machine, model title). Check RLS on `broadcast_messages` (`target_emails` readable by anon).

### 6. Delivery
- `checks.yml` running `tools/checks/*` + py_compile on PR; `mirror.yml needs: checks`.
- Installer version from git tag; GitHub Release `.exe`; "What's new X→Y" in Update/Version.

## E. Suggested order

1. **Week 1 — stop the bleeding:** `dee_ui.py` + `eid_int` sweep (fixes 2026), timeouts/caching in telemetry, startup pull async, DeeSYNC close bug, zero-doc guards, CI checks.
2. **Week 2–3 — UI:** finish theme, dark variant, single window class, help button, convert the 8 popup-chain tools.
3. **Week 4+ — consolidate:** publish / links / session / templates merges, remove stubs, DeeControl state file, DeeAI approval mode, installer/release pipeline.
