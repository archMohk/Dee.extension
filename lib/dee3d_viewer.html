How to use

Touch — one finger drags to orbit, two fingers pinch to zoom and slide to pan, a single tap selects an element.

Mouse — left button orbits, right button or middle button pans, the wheel zooms, a click selects.

Menu (☰) — search elements, switch whole categories on and off, and cut the model open with the section box.

Select an element to read its category, family, type and level, then Isolate it or Hide it.

Reset all puts every category, every hidden element and the section box back to how the file opened.
